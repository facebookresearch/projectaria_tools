# Changelog

---
## Version 290
- Live Preview: see the RGB, SLAM and eye-tracking cameras live in the app before you record, from the Live Preview tile in Quick Actions
- Live Preview streams over a direct Wi-Fi link between your phone and glasses (Wi-Fi Aware on iOS 26 and later, Wi-Fi Direct on Android), with no Wi-Fi network or computer needed
- Turn the hand tracking and eye tracking overlays on or off, and open any camera full screen

---
## Version 285
- Start a session as Recording, Streaming, or Recording & Streaming from one setup screen
- Stream live sensor data to a computer over WebRTC, with signaling, room and STUN/TURN settings in the app
- Record full-rate VRS on the glasses while streaming, using a separate recording profile
- Eye Tracking Calibration produces a calibration recording you can pass to MPS with `--calib` for personalized Eye Gaze

---
## Version 275
- (iOS only) New AR Fitment flow to get your recommended glasses size, accessible from the top-right corner of the login screen

---
## Version 270
- Stability and maintenance update with under-the-hood improvements and bug fixes

---
## Version 265
- Capture button recordings now save correctly as Prototype and are downloadable
- Headset Details screen shows the device OS release version (e.g., V20) for easier troubleshooting
- Faster recovery from Bluetooth glitches and more accurate recording status updates

---
## Version 260
- Recording Profiles organized into Recommended, My Profiles, and Specialized tabs
- Cancel an in-progress glasses OS update, with clear error messages if something goes wrong

---
## Version 255
- Time Domain Mapping for wireless multi-device time synchronization
- Customizable recording profiles (copy, share, and create new profiles)
- Action Button configuration
- Bluetooth Audio Pairing for audio playback

---
## Version 245
- Allow overriding recording names in a sequence
